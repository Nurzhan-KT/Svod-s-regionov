📂 Загрузка Excel-отчётов

Файлы (DRB / ODS / DTK и т.д.) кидайте в подходящее окно ниже. Инструмент читает лист Sheet1 — сырую выгрузку из SAP (Склад, Завод, Материал, Партия, количество…). Остальные листы не нужны — все «жёлтые» поля (Тип склада, Регион, РДТ, Вендор, Частота, Цена) инструмент проставит сам на основании накопленных словарей.

Если в загрузке нет файла в окне «Наличие» — итоговый остаток будет рассчитан автоматически: остаток на предыдущую дату + поступление − расход.

Модели оборудования из нарядов без кода материала (файлы «Расход»)

Наряды на установку не содержат код материала СКЛАДа — только название модели. Один раз укажите код материала (как в DRB/ODS/DTK) — свяжется навсегда.

⚠️ Расхождения (тип склада по коду не совпадает с названием)

Правило применяется строго (код склада: начинается с «0» → ЦС, с «1» → МОЛ). Здесь просто список случаев, где название склада намекает на другое — для ручной проверки, ничего не меняется автоматически.

📋 Сводная таблица

Строится по строкам, обработанным на вкладке «Загрузка» (текущая загрузка в памяти браузера). Для строк/столбцов/значений можно отметить несколько полей — они объединятся через «/» в порядке, в котором перечислены в списке.

Настройте параметры и нажмите «Построить»

📈 Прогноз

Прогноз строится по сохранённым снимкам (кнопка «Сохранить снимок» на вкладке «Загрузка»). Чем больше периодов накоплено, тем точнее. Как минимум нужно 2 снимка.
